# 🦖 공룡 키우기

브라우저에서 키우는 다마고치 스타일 공룡 게임. 16비트 컬러 도트(부품 조립식 애니메이션), 정글·늪지·화산·유적 배경, 실제 시간대별 하늘. `index.html` 하나로 동작하고 저장은 브라우저(localStorage)에 됩니다.

플레이: https://hapsung-yongsadan.github.io/dino/

## 기능
- 성장: 알(1분) → 아기 → 꼬마(Lv.5) → 어른(Lv.12) → 궁극(Lv.25)
- 진화 6갈래 × 궁극진화: 식성(고기/풀) × 가장 높은 능력치(힘/속도/지능)
  - 티라노 · 랩터 · 스피노 · 트리케라톱스 · 프테라노돈 · 브라키오
- ⚔️ 사냥: 턴제 전투(공격/필살기/아이템/도망), 사냥터 4곳(풀밭·늪지·화산지대·고대 유적)
  - 몬스터 5마리 처치 시 보스 등장, 보스 첫 처치 보너스
  - 레벨업, HP/공격/방어/속도/치명, 공룡 종류별 필살기와 보너스
- 🔁 자동 사냥(방치형): 공룡이 사냥터를 걸어 다니며 혼자 싸움, 앱을 꺼도 최대 8시간 진행 후 결과 요약
  - 배고프면 가방 속 도시락을 꺼내 먹고, 위험하면 회복약 사용
  - 레벨이 너무 높은 사냥터는 보상 감소 → 다음 사냥터로 유도
- 🦕 공룡 무리: 공룡알 부화 → 같은 종류·같은 ★ 2마리 합성으로 ★1~★5 진화 → 최대 3마리 출전(따라다니며 공격·HP·방치 EXP 보너스)
- 탐험(숲·바다·화산·동굴): 코인, 아이템, 화석 획득
- 훈련, 점프 미니게임, 가방, 상점(아이템·화면 테마)
- 공룡 도감 / 화석 도감 (세대가 바뀌어도 유지)

## 테스트
주소 뒤에 `?speed=60` → 실제 1분 = 게임 1시간

## 💎 영자코인
- 운영자가 `admin.html`에서 선물 링크를 만들어 보내면, 받은 사람이 링크를 눌러 받음
- 링크는 운영자 비밀키로 서명되어 위조 불가, 1회만 사용 가능, 받는 사람 ID 지정 가능
- 영자 상점: 만능 회복, 탐험 즉시 귀환, 코인 교환, 부활권, 진화 확정권, 특별 테마
- 비밀키는 저장소에 없음 (운영자만 보관)
